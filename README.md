## 🔐 Security Engineering

I focus on implementing security controls as part of application architecture rather than treating authentication as a standalone feature.

- JWT access-token authentication.
- Refresh-token generation, hashing, rotation, revocation, and expiration.
- HttpOnly cookie-based refresh-token handling.
- Stateless API security using Spring Security.
- Role-based access control and permission enforcement.
- Resource-level authorization to help prevent Broken Object Level Authorization (BOLA).
- Account-status and account-lock validation.
- BCrypt password hashing.
- Session tracking and individual session revocation.
- Input validation and database constraints.
- CORS configuration and HTTPS/TLS deployment.
